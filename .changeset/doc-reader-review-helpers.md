Headless helpers for apps that build their own review UI on test runs: `listTestRunHeads` (runs without results), `sampleFieldViews` (a sample's fields with the expected value saved now, the read value, status and evidence box), `fieldStatus`, `isWrongStatus`, `sampleErrors`, `errorsBySample`, `runProblems`, `pickSampleRun` and `isHeldOutSplit`. The admin's sample view uses the same status rules.
