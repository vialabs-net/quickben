The source of truth is [`ARCHITECTURE.md`](https://github.com/vialabs-net/quickben/blob/trunk/ARCHITECTURE.md) in the repository. This page is a summary.

Dependencies point one way. Adapters and other packages depend on `@quickben/core` as a peer dependency. Core depends only on Zod.

## Layers

```
quickben.config.ts      collections, fields, access, hooks, plugins
        │
        ▼
defineConfig            applies plugins in order, validates slugs and relations
        │
        ▼
local API (qb)          access → hooks → Zod validation → relations → transaction
        │
        ▼
DatabaseAdapter         memory, Drizzle (Postgres, PGlite, SQLite), others later
```

The [route handlers](/docs/nextjs/route-handlers) and the [admin UI](/docs/nextjs/admin) call the local API. They do not talk to the adapter directly.

## Core responsibilities

| Concern           | Done by | Detail                                                                   |
| ----------------- | ------- | ------------------------------------------------------------------------ |
| Types             | core    | Inferred from fields. No code generation.                                |
| Validation        | core    | Zod 4 schemas generated from fields, then field `validate`.              |
| Access            | core    | Rules per operation; filters AND-ed with queries.                        |
| Hooks             | core    | Run inside the write transaction.                                        |
| Relations         | core    | Stored as ids; loaded by core with `depth` (0–3).                        |
| Cursors           | core    | Keyset positions turned into `where` filters.                            |
| Ids               | core    | UUIDv7.                                                                  |
| Storage and query | adapter | `find`, `findOne`, `count`, `create`, `update`, `delete`, `transaction`. |
| Unique values     | adapter | Throws `ConflictError`.                                                  |
