# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/vialabs-net/quickben/security/advisories/new). Do not open a public issue.

Include the affected package and version, steps to reproduce, and the impact you expect. You will get a reply within 7 days.

## Supported versions

Quickben is alpha. Only the latest published version gets fixes.
