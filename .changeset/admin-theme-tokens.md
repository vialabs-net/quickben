Admin theme without CSS: `createAdminPage` takes `theme`, a typed object for the `--qb-*` tokens, and `logo`, shown before the title in the sidebar. New optional tokens: `--qb-heading-text`, `--qb-border-strong`, `--qb-accent-hover`, `--qb-selected`, `--qb-danger-strong`, `--qb-success-strong`, `--qb-button-radius` (pill buttons with `9999px`) and `--qb-card-shadow`. Defaults keep the current look. `themeStyle` and `AdminTheme` are exported.
