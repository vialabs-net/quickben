New `@quickben/plugin-templates` 0.1.0: brands, versioned document templates per kind (one draft and one immutable published version), kinds registered with `defineTemplateKind`, a condition language without eval, validation that points at nodes, HTML rendering with a letterhead, a pluggable PDF renderer with a Chromium implementation (`@quickben/plugin-templates/chromium`), and an admin extension with a lazy-loaded TipTap editor, live preview, publishing and a Brand page (`@quickben/plugin-templates/admin`).
