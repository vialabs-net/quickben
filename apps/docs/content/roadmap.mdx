# Roadmap

Quickben is alpha. This list is the current plan. Order and scope can change. Follow progress on [GitHub](https://github.com/vialabs-net/quickben).

## 0.1

| Item              | Package                | Status                                                         |
| ----------------- | ---------------------- | -------------------------------------------------------------- |
| Drizzle adapter   | `@quickben/db-drizzle` | Merged. Postgres, PGlite, SQLite; `quickben-drizzle generate`. |
| Route handlers    | `@quickben/next`       | Merged. REST for every collection, server helpers.             |
| Admin UI          | `@quickben/admin`      | Merged. Dashboard, list, create and edit, extensions.          |
| Playground        | `apps/playground`      | Merged. See [Playground](/docs/playground).                    |
| First npm release | all packages           | Not published yet.                                             |

## Later

| Item                        | What it adds                                                         |
| --------------------------- | -------------------------------------------------------------------- |
| Connections and credentials | Store and use credentials for third-party services per organization. |
| Document templates          | Generate documents from templates and collection data.               |
| Document reading            | Extract data from uploaded documents into collections.               |
| Release train               | Versioning and release tooling for apps built on Quickben.           |
| `create-quickben`           | `pnpm create quickben` scaffolds a new app.                          |
| More adapters               | A document-store adapter (for example MongoDB) without core changes. |
| Spanish docs                | A Spanish version of this site.                                      |
